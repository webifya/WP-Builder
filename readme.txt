A theme-friendly visual builder for WordPress content.

== Description ==

Pagevia stores a versioned builder document in post meta and renders inside the active theme's normal content pipeline. Version 0.8 introduces the Pagevia brand, legacy-data migration and live Pro dynamic tags.

== Installation ==

1. Upload the plugin directory to `/wp-content/plugins/`.
2. Activate Pagevia.
3. Open any editable public post type and choose "Edit with Pagevia".
