A theme-friendly visual builder for WordPress content.

== Description ==

Pagevia is a stable visual site-builder foundation with live editing, responsive controls, reusable templates, autosave, revisions and accessible frontend output.

== Installation ==

1. Upload the plugin directory to `/wp-content/plugins/`.
2. Activate Pagevia.
3. Open any editable public post type and choose "Edit with Pagevia".

== Frequently Asked Questions ==

= Does Pagevia replace my theme? =

Free pages render through the active theme's normal content pipeline. Pagevia Pro can optionally provide complete theme templates.

= Is existing builder content removed on uninstall? =

No. Pagevia preserves documents by default to prevent accidental data loss.
