# Product roadmap

The feature catalog is a product program, not a single release. Shipping order is driven by data stability, accessibility, security, compatibility, and testability.

## 0.1 — Foundation (this milestone)

- Plugin lifecycle and namespaced services
- All editor-capable post types
- Versioned document persistence and validation
- Theme content-pipeline rendering
- Initial layout and content renderers
- Free/Pro extension boundary

## 0.2 — Usable visual editor

- Isolated live canvas, drag/drop, selection, navigator, context menu
- Undo/redo command history, copy/paste, duplicate, autosave/drafts
- Section/container/row/column and complete free-widget registry
- Responsive controls, global colors/type, keyboard accessibility

## 0.3 — Templates and release hardening

- Import/export, saved sections/pages, revisions UI
- PHPUnit, Playwright, PHPStan, ESLint, PHPCS and compatibility matrix
- Performance budgets, accessibility audit, localization and WordPress.org packaging

## 1.0 — Stable free release

All advertised Free features implemented, documented, tested, and migration-safe.

## Pro sequence

1. Theme Builder and dynamic tags
2. WooCommerce builders
3. Advanced widgets and design/motion
4. Forms, integrations, marketing and popups
5. Performance tooling, developer APIs and teams
6. AI features with explicit provider keys, quotas, privacy controls and fallbacks
7. Template library (content volume grows independently from plugin releases)

Future Agency/Ultimate capabilities remain separate commercial planning items.
