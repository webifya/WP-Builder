# Product roadmap

The feature catalog is a product program, not a single release. Shipping order is driven by data stability, accessibility, security, compatibility, and testability.

## 0.1 — Foundation (this milestone)

- Plugin lifecycle and namespaced services
- All editor-capable post types
- Versioned document persistence and validation
- Theme content-pipeline rendering
- Initial layout and content renderers
- Free/Pro extension boundary

## 0.2 — Usable visual editor (completed)

- Authenticated frontend shell, live canvas, drag/reorder, selection and navigator
- Undo/redo command history, duplicate/delete, save and keyboard shortcuts
- Nested layout elements and initial usable widget set
- Responsive canvas, per-device styles and device visibility

## 0.3 — Daily-use editor workflows (completed)

- Context menu, clipboard copy/paste and local crash recovery
- WordPress Media Library integration
- Global color and typography tokens
- Portable page import/export with format validation
- Revision browser and secure restoration

## 0.4 — Layout, widgets and reusable templates (completed)

- Server-side saved page templates with insert/delete workflows
- Accessible tabs, accordion and toggle widgets
- Flex/grid controls and nested drag targets
- Document byte/node limits and Media Library compatibility fixes
- WordPress 7.0 compatibility metadata

## 0.5 — Release hardening (completed)

- Completed initial Free widget editor/renderer coverage
- Added semantic interactive output and keyboard tests
- Added PHP 8.1–8.4 syntax CI and JavaScript browser tests
- Added WordPress 7.0.2 Playground configuration and distribution exclusions

## 0.6 — Production release candidate

- Full installed end-to-end editor suite on classic and block themes
- PHPCS, PHPStan, PHPUnit and Plugin Check with zero-error gates
- Performance budgets, localization extraction and formal accessibility audit

## 0.8 — Pagevia rebrand (completed)

- Renamed public APIs, assets, storage and packages with bounded legacy migration
- Connected Free rendering to licensed Pro dynamic tags

## 0.9 — Production Theme Builder API (completed)

- Exposed reusable document rendering for Pro theme locations
- Enabled visual editing for saved theme templates
- Added dynamic-tag insertion configuration

## 1.0 — Stable free release

All advertised Free features implemented, documented, tested, and migration-safe.

## Pro sequence

1. Theme Builder and dynamic tags
2. WooCommerce builders
3. Advanced widgets and design/motion
4. Forms, integrations, marketing and popups
5. Performance tooling, developer APIs and teams
6. AI features with explicit provider keys, quotas, privacy controls and fallbacks
7. Template library (content volume grows independently from plugin releases)

Future Agency/Ultimate capabilities remain separate commercial planning items.
